# metrics/ — suivi dans Git

Archive des métriques produites par `scripts/evaluate.py` (JSON horodatés :
mAP par classe, FPS mesurés). Contrairement à `data/` et `models/`, ce dossier
**est suivi par Git** : les métriques sont petites, diffables, et constituent
la preuve publique des chiffres annoncés dans le README.

Règle du projet : aucun chiffre n'entre dans le README s'il ne sort pas d'un
fichier de ce dossier.
