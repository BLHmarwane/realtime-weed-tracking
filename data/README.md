# data/ — hors Git

Ce dossier reçoit le dataset (images + labels YOLO + `data.yaml`) téléchargé
par `scripts/download_dataset.py` au milestone M1.

Tout son contenu est **ignoré par Git** (voir `.gitignore`) : les datasets ne
sont jamais commités. Seul ce README est suivi pour que le dossier existe.

Règle du projet : la **licence** du dataset est vérifiée et notée dans
`STATE.md` avant tout téléchargement.
